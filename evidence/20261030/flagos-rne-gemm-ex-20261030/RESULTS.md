# GraphCast FlagOS GEMM_EX RNE 验证 · 2026-10-30

GEMM_EX 的 RNE 覆盖已修复，两个 Linear、24 项接口探针、整模型单步及三轮 40 步均完成。对指定 H100 TF32 baseline 的末帧误差通过内部 5% 线及阶段 10% 线；本次 FlagOS 性能低于既有海光原生 JAX 融合结果，尚需优化。

## 测试配置

- BW1100 单卡，物理卡 8，PCI `0000:85:00.0`（驱动显示 BW1200）。
- 容器 `flagos-jax-test`，镜像 `flagos-r6-optimization-test:20261026-c93db685-bw59-hal642`，ID `6d4813ee61bb39a439d96bb28b62371628d9eb0a2e62cc4a84a5218403bb0aad`。
- JAX/jaxlib 0.6.0，FlagTree `0.7.0rc2+hcu3.6.glibc228.compat1.git76201fd9`，DTK 26.04；`XLA_MODE=fl_only`，FP32 数组、RNE＋XF32，GEMM 仍为 rocBLAS。
- 官方源码 `08cf73625c9d12bd9aaa038868bcb2fe488f2a22`；固定原预训练权重、0.25°全球网格、13 层、batch=1；每轮预热 5 步后重置输入，自回归 40 步。
- 对照为 gpu41 于 2026-10-29 冻结的 H100 80GB JAX TF32（无显式 RNE）。数据标识、源码版本和输出校验值均已核对。

## 修复及路径验证

原适配仅拦截 SGEMM，两个 K=4 Linear 走 GEMM_EX 时完全绕过 RNE。候选实现覆盖两个入口，保留 C/D 分离语义、步长、alpha/beta、算法、solution index、flags 和原数学模式恢复；原 baseline 未改动。

| 检查 | 结果 |
| --- | --- |
| 两个 Linear 回归 | 均通过；每次实际 GEMM_EX＋RNE 覆盖增量为 1/1，未知权重为 0 |
| 24 项接口探针 | 转置、C≠D、beta、输出 padding、FP32/XF32/RNE 和模式恢复均通过，输入未被修改 |
| 整模型单步 | 82 次 SGEMM＋2 次 GEMM_EX，84 次全部覆盖 RNE，79 次 producer RNE 融合保留 |
| 实际设备内核 | 81 次 XF32 MX 内核；3 次 K=4 原生 FP32 回退；89 次独立 RNE 内核 |
| 三轮完整执行 | 120 个测量步＋15 个预热步，11,340 次 GEMM，所有步均通过 84/84 覆盖和 79 次融合检查 |

K=4 回退属于原 rocBLAS 行为，SGEMM/GEMM_EX 均可复现；请求 XF32 不代表每个尺寸都使用 XF32 指令。候选对这些回退仍执行显式 RNE。K=512 单位映射探针已用精确结果证明真实 XF32 截断及 RNE 修正，不能只凭 math-mode 回读作此判断。

两个 Linear 的独立同步调用中位耗时分别为 **7.465 ms**（N=1,618,745）和 **1.541 ms**（N=327,660）。这是独立算子墙钟口径，不是整模型内核归因时间。

## 性能

| 路径 | 40 步端到端中位数 | 单步 GPU 活跃区间并集 |
| --- | ---: | ---: |
| H100 JAX TF32，10/29 冻结参考 | 14.472 s | 315.199 ms |
| 既有 BW1100 原生 JAX 融合 RNE＋XF32，10/22 历史结果 | 33.311 s | 724.393 ms |
| 本次 BW1100 FlagOS JAX (`fl_only`) | **58.616 s** | **1,349.381 ms** |

本次三轮端到端分别 58.766、58.524、58.616 s；同步 predictor 调用累计中位数 54.658 s（H100 为 12.719 s）。端到端含传输、自回归输入更新，排除加载、编译、预热、指标计算和写盘。单步 profile 在预热后采集，不能乘 40 写成实测卡上时间。旧海光结果为历史比较，非本次同环境 A/B 重测。

MFU 估算为 `28.784948924416 / (1.349381105 × 170.3936) = 12.5192%`，使用 84 次逻辑 GEMM 的有效 FLOPs 近似及单步 GPU 活跃时间。未做硬件峰值归一化的吞吐比为 H100 的 24.69%（端到端）/23.36%（单步卡上），**不能据此判定合同“同等算力 60%”**。

| 设备内核类别 | 累计耗时 | 占比 |
| --- | ---: | ---: |
| Gather 相关融合 | 416.450 ms | 30.86% |
| Scatter 相关融合 | 363.202 ms | 26.92% |
| GEMM | 315.560 ms | 23.39% |
| LayerNorm 相关融合 | 92.089 ms | 6.82% |
| 独立 RNE | 15.055 ms | 1.12% |
| 其他 | 147.029 ms | 10.90% |

融合类别包含其中的 Concat、RNE 等工作，不等同于逐个逻辑算子的独立耗时；独立 RNE 1.12% 也不是全部 RNE 成本。下一步优先检查 Gather/Concat/RNE 与 Scatter 的 FlagTree 生成内核，而非替换 rocBLAS。

容器内 hy-smi 读取 `/dev/mkfd`/服务失败，记录中的板卡遥测不完整；设备 trace 已采到完整 338 个计算内核，另保存了宿主机遥测。活跃采样显示卡 8 为 100%，显存 37,756 MiB，sclk 1350 MHz、fclk 1300 MHz；这不是显存峰值统计，也不是锁频承诺。
