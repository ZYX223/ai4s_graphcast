最近偶数舍入 + XF32：位运算教学 Demo

用途
  解释“FP32乘法输入先舍入到10位显式小数，再交给XF32”的预处理逻辑。
  核心表达式与已验证的HIP GPU版本一致。本包可在普通CPU上运行。

文件
  rounding_demo.cpp    带中文注释的完整C++示例，包含预期值检查。
  example-output.txt   本机编译运行得到的实际输出。

运行方法（进入本文件所在目录）
  g++ -std=c++11 -O2 -Wall -Wextra -Wpedantic rounding_demo.cpp -o rounding_demo
  ./rounding_demo

需要：支持C++11的编译器，float采用IEEE 754 binary32。
不需要Python、JAX、HIP、CUDA或GPU。不要添加-ffast-math类选项来改写浮点语义。

建议阅读顺序
  1. round_to_10_bits_rne：核心舍入函数。
  2. examples：原始值、向零截断、最近偶数舍入对照。
  3. explain：逐步打印低13位、保留位、加数及进位情况。
  4. identity_demo：将同一组数放进2×2矩阵，比较A×I。

最关键的一行
  bits = (bits + 0x00000fffu + ((bits >> 13) & 1u)) & 0xffffe000u;

含义
  FP32：1位符号 + 8位指数 + 23位显式小数。
  保留10位小数，需要清掉低13位。编码间隔为8192，中点为4096。
  加上4095，再根据保留部分最低位补0或1，决定是否进位；最后清掉低13位。
  小于中点不进位，大于中点进位，恰好中点则让保留部分的最低位为0。
  “取偶数”指保留编码的最低位为0，不是要求浮点数为整数。
  RNE = round to nearest, ties to even，即最近偶数舍入。

几个可手算的例子
  更靠近上邻值：1.000732421875 -> 截断1.0；RNE 1.0009765625。
  中点、保留部分偶数：1.00048828125 -> RNE 1.0。
  中点、保留部分奇数：1.00146484375 -> RNE 1.001953125。
  负数：-1.000732421875 -> 截断-1.0；RNE -1.0009765625。

和实际GPU实现的对应关系
  float_to_bits(x)  对应 __float_as_uint(x)：按位解释，不是把数值转成整数。
  bits_to_float(u)  对应 __uint_as_float(u)：把编码重新解释为FP32。
  GPU对矩阵的每个元素执行同样的处理，在同一stream上继续调用Native XF32 GEMM。
  结果仍用FP32存储；这里没有将数据类型转换为FP16或BF16。

适用范围
  A×I部分是CPU数值模拟，用于直观看到输入舍入效果；它没有调用真实XF32硬件，
  也没有模拟一般稠密矩阵乘法的GPU累加顺序，不能用于推断性能或模型精度。
  程序中的MAE降幅只属于这个4元素例子。
  进位可能改变指数；极大有限数可能舍入成Inf，极小值可能舍入成带符号的0。
  NaN/Inf编码直接保留。真实GPU对次正规数的处理还取决于计算路径。
