# BW1100：RNE＋XF32 推理 profile 与独立算子测试

本轮已核对官方源码、数据/权重、历史参考及设备记录，测量官方 JAX GraphCast 的 RNE＋XF32 路径。核心发现：单步 GPU 内核累计时间中，GEMM 占 33.16%，RNE 占 29.36%；舍入成本主要来自激活，权重占比很小。

## 固定条件与计时范围

- 官方提交 `08cf73625c9d12bd9aaa038868bcb2fe488f2a22`，16 个模型文件字节未修改；复用周报输入、权重与归一化统计量。
- Operational 0.25°，721×1440，13 层，batch=1。输入、权重、输出以 FP32 存储；84 次 GEMM 均先将两个输入做最近偶数舍入，再使用 XF32。
- Hygon_ZYX，项目型号 BW1100；原始驱动/JAX 名 BW1200，gfx938，DTK 26.04，JAX `0.6.0+das.opt1.dtk2604`。
- 本次 GPU11、PCI `0000:9c:00.0`，启动前空闲。历史周报 GPU9 的记录单独保留。使用固定容器，未修改共享机器的功耗、频率、全局 THP 或其他任务。
- 整模型先预热 5 步，再从初始输入重新开始，用 hipprof 捕获 **1 个 +6h 推理步**；包括 Grid2Mesh、Mesh、Mesh2Grid、模型归一化及该步执行中的传输。编译、权重加载和预热不在捕获范围。
- 本次是瓶颈分析，不重新测量 40 步性能或最终误差；不能将该步时间乘 40 当成新周报结果。原有 40 步精度验收口径不变。

## 整模型实测结果

有效运行：`model-profile-rne-r3`，摘要 `profile-summary-r3`。计时单位 ms。

| 内核类别 | 次数 | GPU 累计时间 | GPU 内核时间占比 |
|---|---:|---:|---:|
| GEMM | 84 | 321.335 | 33.16% |
| RNE 舍入 | 168 | 284.469 | 29.36% |
| 含 Scatter 的融合内核 | 18 | 105.831 | 10.92% |
| LayerNorm 相关融合内核 | 192 | 105.034 | 10.84% |
| 其他设备内核 | 68 | 91.828 | 9.48% |
| 含 Gather 的融合内核 | 20 | 60.529 | 6.25% |
| 合计 | 550 | 969.025 | 100% |

分类依据为实际 GPU kernel 名与优化 HLO。融合内核的整个耗时归入一个类别；其中可能同时包含 Gather、Scatter、LayerNorm、激活等操作，不能把整段时间解释为一个纯算子的时间。分类按优先级互斥，CSV 另保留重叠的 HLO 语义标签。

该步带 profiler 的 rollout 为 1058.865 ms，同步模型调用为 1020.378 ms，GPU kernel 时间区间并集为 969.023 ms。另有 24 次设备复制、累计 27.392 ms，以及 2031 次主机 HIP API、累计 42.827 ms。主机 API、复制与 kernel 可能重叠，不相加为端到端时间；上述百分比的分母只包含 GPU kernel 累计时间。

两次有效单步采样 r1/r3 的 kernel 累计时间分别为 970.106/969.025 ms，主要分类占比接近；r3 提供完整逐层关联。它们不作为正式三轮端到端性能统计。

## 舍入成本定位

将本步 84 条原生 GEMM 记录与同流 `权重 RNE → 激活 RNE → GEMM` 设备事件逐一配对，并校验全部权重指纹、形状及数学模式：

| 项目 | 本步 GPU 累计时间 | 占 RNE 时间 |
|---|---:|---:|
| 权重舍入 | 3.933 ms | 1.38% |
| 激活舍入 | 280.536 ms | 98.62% |

以下只统计各阶段的 GEMM 和 RNE，不代表整个阶段的完整耗时：

| 阶段 | GEMM 次数 | GEMM | 激活 RNE | 权重 RNE |
|---|---:|---:|---:|---:|
| Grid2Mesh | 10 | 68.260 ms | 55.534 ms | 0.253 ms |
| Mesh | 66 | 128.254 ms | 116.418 ms | 3.427 ms |
| Mesh2Grid | 8 | 124.820 ms | 108.584 ms | 0.253 ms |

最耗时的单次激活舍入是 Mesh2Grid 边 MLP 的 `linear_0`：激活 `[3114720,1536]`、权重 `[1536,512]`，舍入 51.685 ms，随后 GEMM 51.983 ms。Mesh processor 的边 MLP 首层则重复 16 次，需要同时关注累计成本。

后续优先评估激活舍入与 GEMM 读取/输入构建融合，减少中间缓冲区的读写。仅缓存权重舍入，即使完全消除本步相关 kernel，当前直接可省也仅约 3.9 ms；不能据此承诺端到端加速比例。本轮没有修改 RNE 数值算法或实施融合优化。

## 独立矩阵测试

15 种实际 GEMM 形状覆盖模型每步 84 次调用。使用固定种子的合成 FP32 输入，原生列主序 `A[m,k] × B[k,n] → C[m,n]`，`alpha=1,beta=0`。模型逻辑布局为激活 `[n,k]`、权重 `[k,m]`、输出 `[n,m]`。

每种尺寸测三轮，每项先预热 5 次，随后用 HIP events 测 20 次操作的平均时间。测试 RNE＋GEMM、预舍入输入的 GEMM、仅权重舍入、仅激活舍入；不测新的 FP32 / 原始 XF32 对比。构建、分配、输入生成和正确性检查不计时，独立代码也不包含整模型路由开销。

按实际调用频次加权后，各轮加权总量的中位数为：

| 独立测试项 | 加权时间 |
|---|---:|
| RNE＋GEMM | 631.062 ms |
| 预舍入输入的 GEMM | 353.856 ms |
| 仅激活舍入 | 272.885 ms |
| 仅权重舍入 | 0.832 ms |

这是合成输入独立测试的加权估计，不是整模型耗时、GPU 占比或端到端性能。各项独立测量、缓存状态不同，中位数不保证相加相等；权重在独立重复运行中更热，不能用其 0.832 ms 替换模型 trace 的 3.933 ms。

正确性检查包含：每个输入 257 个分布位置与独立商/余数 RNE 参考比较；32 个输出坐标与独立 FP64 点积比较；两个原始输入缓冲区全量位级不变；两次使用相同预舍入输入的 GEMM 全输出位级一致。最后一项是执行一致性，**不等于所有输出都与独立数学参考逐个比较**。完整原始舍入探针另覆盖 100227 个位模式及非连续布局。

15 种尺寸全部通过；抽样 GEMM 与舍入后 FP64 点积的最大绝对差为 `3.544e-6`。

14 项全部通过。图索引由固定官方模型和输入经纬度生成；Grid2Mesh、Mesh、Mesh2Grid 分别有 1618745、327660、3114720 条边。特征采用固定种子的合成 FP32 数据，通道数 512，batch=1 展平。每项三轮，每轮预热 5 次、测 20 次，以下为 60 次同步 JAX 调用时间的中位数，单位 ms。

| Mesh | 0.851 | 0.815 | 3.479 |

| LayerNorm 输入行数（每行 512 通道） | 时间 |
|---|---:|
| 40962 | 0.288 |

每项检查 32 个输出行的全部 512 个通道；Gather 与输入索引结果一致，Scatter 对所选节点全部入边使用 CPU FP64 求和，LayerNorm 使用 CPU FP64 均值/方差和仿射参考。Scatter 最大绝对误差为 `1.091e-5`，LayerNorm 为 `6.216e-7`。小尺寸 CPU 单测另验证全部输出、重复索引、空节点和常量行。

这些图操作没有 GEMM，保持 FP32 运算；“只测 RNE＋XF32”指本轮整模型的矩阵精度路径，并非将归一化或聚合变成 XF32。独立图操作没有复现整模型 XLA 融合，包含 JAX 调度与同步成本，不能把本表时间直接代入整模型融合内核占比。
